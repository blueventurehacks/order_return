# Return Pipeline

A full-stack application for managing e-commerce returns, built with modern web technologies. This application provides a seamless experience for customers to initiate returns, track their status, and for administrators to manage the return process efficiently.

## Features

- **Customer Portal**
  - Submit return requests with order details
  - Track return status in real-time
  - View return history

- **Admin Dashboard**
  - Process return requests
  - Handle refunds and exchanges
  - Generate return labels
  - Fraud detection and prevention

- **API Endpoints**
  - Order management
  - Return processing
  - Refund handling
  - Shipping integration
  - Fraud detection

## Tech Stack

### Backend
- **Framework**: FastAPI (Python 3.10+)
- **Database**: SQLite (with SQLAlchemy ORM)
- **Authentication**: JWT (JSON Web Tokens)
- **API Documentation**: Swagger UI (automatically generated by FastAPI)

### Frontend
- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **UI Library**: Material-UI (MUI)
- **State Management**: React Query
- **Form Handling**: React Hook Form

## Prerequisites
- Python 3.10+
- Node.js 18+
- npm or yarn

## Getting Started

### Backend Setup

1. **Set up the virtual environment and install dependencies**
   ```bash
   cd /path/to/return_order_hackathon
   python -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   # On Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Configure environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

3. **Run database migrations**
   ```bash
   alembic upgrade head
   ```

4. **Start the backend server**
   ```bash
   uvicorn app.main:app --reload
   ```
   The API will be available at `http://localhost:8000`
   - API documentation: `http://localhost:8000/docs`
   - Alternative docs: `http://localhost:8000/redoc`

### Frontend Setup

1. **Install dependencies**
   ```bash
   cd frontend
   npm install  # or yarn install
   ```

2. **Configure environment variables**
   Create a `.env` file in the frontend directory based on `.env.example`

3. **Start the development server**
   ```bash
   npm run dev  # or yarn dev
   ```
   The frontend will be available at `http://localhost:3000`
